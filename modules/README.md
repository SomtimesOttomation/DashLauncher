# Dashboard modules

Each dashboard module goes here in its own folder, for example:

```
modules\
  NBADash\
    dash.json
```

Published dashboards show in DashLauncher as greyed tabs: click one for its download link, extract the zip into a new
folder here, and press Refresh. DashLauncher also looks in this folder every time it starts, and when you press Scan for
modules. DashLauncher's own updates never change this folder.
